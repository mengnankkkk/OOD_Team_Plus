# 提醒中心上线说明

提醒中心只发布可追溯的行情事实、组合风险和用户自定义阈值，不在后台自动生成买卖指令。需要主观判断时，提醒会携带标的、指标值、行情时间和用户关注理由进入现有顾问对话，由顾问完成支持证据、反方证据、组合影响和情景方案分析。

## 默认提醒规则

| 类型 | 默认阈值 | 级别 | 数据来源 |
| --- | --- | --- | --- |
| 持仓亏损 | 相对成本收益率不高于 -8% / -15% | 重要 / 紧急 | 最新持仓快照 |
| 浮盈复核 | 相对成本收益率不低于 15% / 30% | 关注 / 重要 | 最新持仓快照 |
| 单一持仓集中度 | 权重不低于 35% / 50% | 重要 / 紧急 | 组合计算引擎 |
| 持仓异动 | 较上次快照绝对变动不低于 5% / 8% | 关注 / 重要 | Pandadata 行情快照 |
| 组合风险评分 | 风险评分不低于 70 / 85 | 重要 / 紧急 | 组合健康度引擎 |
| 自选单日异动 | 绝对涨跌不低于 4% / 7% | 关注 / 重要 | Pandadata 日行情 |
| 自选回撤 | 较近 20 个交易日高点达到用户设置阈值，默认 10% | 关注 / 重要 | Pandadata 日行情 |
| 数据质量 | 部分标的使用历史价格 | 信息 | 行情刷新结果 |
| 数据陈旧 | 持仓快照超过 72 小时 | 关注 | 快照时间 |
| 自定义条件 | 价格上穿、下穿、浮盈或回撤越线 | 重要 | 观察条件引擎 |

同一用户、同一标的、同一规则在同一行情日期只生成一次提醒。规则跨越更高风险级别时可生成新的升级提醒；被忽略的提醒不再出现在活动列表，但审计记录仍保留。

## 运行方式

Node 常驻进程启动后每小时扫描一次有活动持仓或自选标的的用户。用户打开提醒中心时会执行一次带冷却的规则评估，点击“同步行情”会立即请求 Pandadata 并重新计算提醒。

生产环境通过 Doppler 注入 `DEFAULT_USERNAME`、`DEFAULT_PASSWORD`、`JAVA_SERVICE_BASE_URL` 和现有模型变量：

```bash
doppler run -- docker compose up -d
```

不得为 Docker 创建本地真实 `.env` 文件。行情接口失败时，系统保留最近一次有效快照并将同步状态标记为“部分可用”，不会把回退价格冒充为实时行情。
